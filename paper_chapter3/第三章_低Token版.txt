   第三章 基于 Yolov11 的微小无人机检测架构设计与实现

  本章作为全文的核心理论内容，重点论述针对远距离与高机动无人机目标识
别算法的架构设计与底层实现过程。本章首先重点分析了基准检测模型的基础理
论及其在微小目标探测场景下暴露的性能缺陷，随后详细阐述基于上下文锚点注
意力 CAA[16]的首次特征增强方案，在此基础上，本章全面推演所构建的高性能检
测架构 YOLOv11n-MEDA 在多头拓扑重构、空间特征保真、高频边缘增强与难例
回归优化等维度的原理机制，并最终通过严密的定量实验数据论证各项算法重构
策略的实际成效。


3.1 Yolov11 检测原理与无人机探测的物理缺陷
  Yolov11 延续并深化了单阶段目标检测器的高效设计哲学，其主干网络通过大
量堆叠 C3k2 与 C2PSA 模块，利用跨阶段局部网络思想实现了梯度的深度流动与
特征的有效提纯。然而，当将该基准模型直接应用于开阔复杂环境下的无人机探
测任务时，其固有的网络拓扑与算子特性会有较明显的物理局限性。
  首先是特征剥落现象，根据卷积神经网络的感受野与下采样原理，Yolov11 的
最小检测头 P3 层经历了像素步幅达八倍的缩减。对于在极端远距离下进行侦测的
摄像机画面而言，无人机在 640  640 的图像中往往仅占据不足 8  8 像素的微小面
积。这意味着当该目标的图像特征历经层层卷积传入 P3 层时，其有效特征响应面
积将不足 1  1 像素。这种连续的跨步卷积与池化操作会导致极小目标的语义特征在
深层网络中被平滑与抹除，进而导致系统在远距离预警时漏检率急剧增加。
  除了静态条件下的特征丢失，无人机的高速机动性也给视觉检测带来了另一
困难，即动态模糊。在实际追踪过程中，由于摄像机的快门曝光时间以及目标的
高速横切运动，无人机的旋翼和机架在画面中不可避免地会产生严重的拖影。这
种视觉上的模糊在图像频域中等效于一个强烈的低通滤波器，它极大地削弱了图
像中的高频边缘信号。由于常规卷积核高度依赖锐利的像素梯度变化来精确定界
目标轮廓，高频信号的衰减会导致边界框回归损失函数难以平稳收敛，在最终的
视频流输出中便表现为检测框的剧烈抖动与闪烁。

3.2 基于 Yolov11 的基线模型前期优化与验证
3.2.1 基于 CAA 机制的全局特征增强
  在课题研究初期，为了增强模型在城市楼宇、树林等复杂低空背景下的特征
判别力，本文首先尝试在 Yolov11 基准模型中引入上下文锚点注意力 CAA（Context
Anchor Attention）模块[16]。在传统的视觉注意力机制中，全局自注意力虽然能够
捕获极长距离的像素依赖，但其计算复杂度随特征图分辨率呈平方级增长，显然
无法满足无人机边缘计算平台的实时性需求。鉴于此，CAA 模块的设计初衷在于
利用极轻量化的卷积算子，高效捕获目标的远程空间依赖关系，以此抑制背景杂
波。在特征处理的首个环节，CAA 模块摒弃了直接对全局特征进行运算的做法，
而是引入了“局部锚点”的概念。具体而言，输入特征 X 首先经过一个核大小为
7  7 、步长为 1 的平均池化层进行处理。这一操作在物理意义上等效于一个抗混
叠的低通滤波器，它在保留局部区域代表性特征的同时，有效滤除了高频的杂乱
背景噪声，生成了平滑的锚点特征 X pool ：
                       X pool  AvgPool77 ( X )               (3-1)

  为了在不显著增加参数量的前提下扩大感受野，CAA 创新性地采用了一维条
带卷积来替代传统的方形大核卷积。对于带有细长旋翼和机臂的十字形或 X 形无
人机目标，水平与垂直方向的结构化特征尤为关键。模块分别利用水平方向的 111
卷积与垂直方向的 111 卷积，沿正交方向逐级提取长距离的上下文信息。这种将
11 11 的二维感受野解耦为两个一维向量叠加的数学操作，不仅极大地缩减了计算
冗余，更精准契合了无人机的物理轮廓分布：
                 Fh  BatchNorm(Conv111 ( X pool ))
                                                               (3-2)
                   Fv  BatchNorm(Conv111 ( Fh ))             (3-3)

  在完成感受野的十字形扩展后，特征张量被送入一层 1  1 逐点卷积，并利用
Sigmoid 激活函数  将数值映射至 [0,1] 区间，从而生成空间注意力权重矩阵 ACAA 。
最终，将该权重矩阵与原始特征 X 进行逐元素相乘，完成特征的重标定：
            ACAA   (Conv11 ( Fv ))(3- 4) X out  X  ACAA   (3-4)

是将 CAA 模块 作为一种即 插即用的 特征提 纯单元，选 择性 部署于主干 网络
Backbone 的多个关键节点处。具体而言，在每个 C3k2 基础特征提取模块之后，系
统均串联了一个 CAA 轻量化注意力层。这一设计使得网络在完成局部卷积特征提
取后，能够立刻通过 CAA 模块的十字形条带卷积与 Sigmoid 重标定机制，对特征

3.2.2 引入 Focaler-IoU 的回归损失优化
  在引入 CAA 模块后，尽管模型对背景噪点的抵抗力有了明显改观，但由于条
带卷积极大地扩展了感受野，导致模型在预测边界框时出现了微弱的定位偏移，
即在高 IoU 阈值下的贴合准确率出现了退化。为弥补这一定位精度的损失，本文
在损失函数环节进一步引入了 Focaler-IoU，该函数创新性地提出了一种基于线性
区间映射的难易样本加权策略[18]。设原始交并比为 IoU ，其映射机制的数学定义为：
                             0,          IoU  d
                              IoU - d
                             
               IoU focaler            , d  IoU  u   (3-5)
                                 u - d
                             1,         IoU  u

  通过人为设定上限阈值 u 和下限阈值 d ，Focaler-IoU 重塑了交并比的分布曲
线。该策略强制模型在训练后期放弃对极易样本的过度优化，转而将梯度深度聚
焦于那些处于特定区间内的困难样本，如难以严密贴合的机翼边缘。这一补偿机
制在保障整体召回率的同时，有效提升了边界框的几何贴合度。然而，综合实验
表明，仅靠注意力机制与损失函数的外部修补，依然无法从根本上改变极端远距
离目标的特征剥落趋势，这促使了本文向更深层的网络架构进行设计重构。


3.3 YOLOv11n-MEDA 架构设计与实现
  在完成前述的特征增强验证后，实验数据表明单纯依赖外部模块叠加与损失
函数替换，极端远距离目标在多次下采样中空间分辨率不可逆衰减的趋势无法改
变。为突破微小目标深层特征剥落与动态边缘模糊的感知问题，本文并未在原有
基准拓扑上进行浅层模块堆砌的常规调优路径，而是跨学科借鉴了医学影像病灶
提取中多尺度边缘融合框架的设计思路[19]，并针对无人机低空高机动飞行的特有
物理属性，对基线网络进行了底层的架构设计。通过解构原始的特征金字塔传递
逻辑，并将高分辨率保真算子与高频残差边缘提取机制进行底层级联，本文系统
性地提出并实现了一种名为 YOLOv11n-MEDA 的高性能微小目标专用检测架构。

3.3.1 高保真特征传递
  在宏观的网络拓扑层面，为实现高保真特征的有效传递，本文突破了常规的
P3-P5 三头检测架构。由于 P3 层经历了 8 倍下采样，远距离无人机目标到达该层
时特征响应已极为微弱，因此本文额外在颈部 Neck 网络中直接引出了主干网络中
的 P2 特征层，由于 P2 层仅经历了四倍的下采样，它在整个特征金字塔中保留了
160  160（基于 640 输入）的更高分辨率空间细节，通过将该层级与深层富含语义
的特征流进行上采样融合，构建了一个极小目标的检测通道，形成了覆盖 P2-P5
的四头尺度架构。
  伴随高分辨率特征层的引入，如何确保特征在不同尺度间缩放时的信息保真
度显得尤为关键。在传统的卷积神经网络中，特征图的空间降维通常依赖于步长
为 2 的跨步卷积，但从信号采样的物理角度来看，这种单一通道的跨步滑动会直
接丢弃掉原特征图中近 75%的空间像素点。对于原本就极其微弱的远距离无人机

目标而言，这种降维方式易导致目标的核心像素被滑动窗口跳过，从而造成不可
逆的结构性信息破损。为了解决这一信息传递困难，本文在特征的下采样环节引
入了 ADown 双分支高保真算子。与传统单路卷积不同，ADown 算子采用了空间
与语义解耦的并行提取策略，即设输入特征张量为 X ，该模块首先利用平均池化
操作作为抗混叠的低通滤波器，在抑制高频背景噪声的同时，保留全局的粗略空

与 X 2 ，左侧分支对 X1 施加 3  3 跨步卷积，旨在深度挖掘特征的内在语义关联，而
右侧分支则摒弃了可能破坏微小轮廓的大核卷积，仅利用 1  1 逐点卷积对 X 2 进行
通道维度的线性映射，以此最大程度地将原始的纯粹空间几何结构直接传递至下
一网络层级。
   其前向传播的完整数学逻辑可严密表述为：
                            X pool  AvgPool ( X )                 (3-6)

                       X1 , X 2  Split ( X pool , dim  1)        (3-7)

                 Yout  Concat (Conv33 ( X1 ), Conv11 ( X 2 ))   (3-8)

   通过将这两路在物理意义上互补的特征信息在通道维度进行重新级联，
ADown 机制在有效压缩特征空间维度的同时，兼顾了深层语义的提取与浅层微小
目标轮廓的保真，从根本上遏制了特征剥落现象的发生。
   在特征金字塔网络的自顶向下融合路径中，如何将深层低分辨率特征图进行
高保真放大，是决定极小目标探测性能的关键环节。传统 Yolov11 架构通常采用最
近邻插值或双线性插值等静态算子进行上采样，其仅根据像素间的几何距离进行
线性加权，完全忽视了图像本身的语义内容，在处理远距离无人机目标时，这种
盲目的插值过程会强行将微弱的目标特征向周围背景像素稀释，导致原本清晰的
机臂或旋翼边缘产生严重的网格伪影与形态模糊。为了克服静态算子的物理局限

该算子通过一个极轻量化的 1  1 卷积层，直接从输入特征图 X 中预测出像素级的

3.3.2 多尺度边缘融合与动态非单调性回归逻辑
   在解决了静态微小特征的保留与传递问题后，本文进一步针对无人机机动飞
行所伴随的动态模糊现象开展了专项优化。本文借鉴了 MEDA-YOLO[19]在图像边
缘提取方面的算法思想，并针对无人机低空飞行场景的物理特性，在特征输出给
检测头之前引入并重新适配了 MSEF（Multi-Scale Edge Fusion）多尺度边缘增强模
块[19]。
   原有的边缘检测算子多用于静态图像，而本研究为了应对不同距离下的动态
拖影，在 MSEF 模块的工程实现中针对性地配置了不同尺寸的平均池化核（如
3  3,5  5 ）对输入的局部特征进行多尺度平滑处理，以此剥离出包含背景拖影的
低频特征图。随后通过计算原始特征与平滑特征之间的数学残差，模块能够显式

强并补偿远距离下无人机边缘的微弱高频响应；而在 P5 层引入，则用于应对无人
机突然抵近侦察时产生的巨大运动模糊拖影，确保了网络在极端尺度变化下的全
频段边缘感知能力。该机制的作用极其显著，即便在摄像机镜头因快速追随而导
致画面出现严重拖影时，它依然能敏锐地突显出无人机微弱的旋翼和支架轮廓。
   在极小目标的探测中，即使经过了 MSEF 模块的边缘增强与高分辨率 P2 层的
特征保留，底层的特征图中依然会不可避免地掺杂环境背景的局部高频噪点。为
了进一步提纯目标特征，本文在 P2 微小目标检测分支后创新性地引入了 EMA
（Efficient Multi-Scale Attention）注意力机制模块。
   与 传 统 的 CBAM （ Convolutional Block Attention Module ） 或 SE
（Squeeze-and-Excitation）空间注意力机制不同，EMA 模块通过跨维度的交互方
式，在不进行通道降维的前提下，保留了通道间的确切信息。它将特征沿两个空
间维度进行池化，并利用一维卷积实现通道权重的跨空间学习。这种机制能够极
其敏锐地捕捉到无人机旋翼、机臂等细长结构的像素级关联，赋予网络对无人机
高频形态特征的强聚焦能力，从而在复杂的背景杂波中进一步拉升了微小目标的
显著性。

3.5.2 训练收敛性分析
  为了直观验证本文所提改进策略的有效性，本节提取了 YOLOv11n 基线模型、

  观察图中四条曲线的全局演进轨迹，在训练的初始阶段（0~50Epochs），所

真引发的极端空间偏差梯度，有效避免了梯度爆炸，使网络在受限的特征条件下
仍能完成较为稳定的几何回归。
   最终，本文提出的 YOLOv11n-MEDA 架构取得了性能上的显著优势。随着学
习率余弦退火，该曲线在 150 轮之后的精细微调阶段实现二次提升，并最终在第
194 轮收敛至 59.07%的最高值，较基线提升了 4.59 个百分点，这一结果验证了本
文算法重构的有效性，即通过剔除深层 CAA 模块避免了空间分辨率的衰减，利用
新增的 P2 高分辨率检测层与 MSEF 多尺度特征融合模块的协同，为坐标回归提供
了高分辨率且边缘清晰的浅层特征，Focaler-IoU 则在安全梯度范围内对困难样本
进行重新赋权。四条曲线的变化对比，表明将算力向浅层高分辨率特征倾斜是提
升小目标定位精度的有效策略，为机电云台系统的稳态时序追踪提供了高质量的
视觉前馈信号。

对比度环境），对 YOLOv11n 基线模型、YOLOv11n-CAA-Focaler 架构以及本文
提出的 YOLOv11n-MEDA 架构的预测结果进行可视化定性对比，如图 3-9、图 3-10、

   从可视化结果的对比中可以归纳出以下三个层面的显著差异。首先是基线模
型 YOLOv11n 的特征感知盲区，在面对像素占比极小的远距离无人机时，基线模
型表现出明显的漏检与错检，如图 3-10（c）和图 3-11（c）所示。由于特征提取
网络经过多次跨步卷积下采样，目标微弱的高频边缘信息在深层网络中被大面积
的背景噪声（如树林、建筑纹理）掩盖，即便在部分对比度较高的场景下能够生
成预测框，其边界框也存在明显的尺度膨胀与中心偏移，无法精确贴合目标的实

在结构缺陷。观察定性可视化结果可知，该模型在基准模型完全漏检的部分困难
              说明 CAA 模块通过十字形条带卷积扩大感受野，
样本上实现了预测框的初步召回，
在一定程度上增强了网络对弱信号目标的感知能力，同时，Focaler-IoU 损失函数
对大偏差样本的梯度重赋权，也使模型初步具备跨越背景杂波的潜力。然而，定
性结果分析也体现出一个问题，由于 CAA 模块过度引入长距离的空间依赖，使大
量无关的背景噪声被赋予了不必要的特征权重。这种特征稀释效应导致网络在定
位时容易受到无人机周围环境光影的干扰，如图 3-11（b）所示，预测框的置信度
普遍偏低，且频繁将树枝间的空隙或远处的飞鸟误识别为无人机目标。这一较高
的虚警率表明，在不改变网络下采样拓扑的前提下，仅靠外部注意力模块的修补，
难以解决亚像素级空间细节丢失的问题。
   最后本文提出的 YOLOv11n-MEDA 架构在所有困难场景中均展现出明显的视
觉感知优势。定性对比结果显示，该架构不仅以高召回率检测出所有处于漏检边
缘的极小目标，且预测框紧密贴合无人机的机身骨架、旋翼支架及物理边缘。该
性能得益于 P2 高分辨率检测头与 DySample 动态上采样算子的跨层协同，使网络
在恢复特征图空间分辨率时实现了对目标拓扑结构的亚像素级重构。该边界框空
间的对齐精度与模型的 mAP50:95 指标 59.07%相符，证明了该网络拓扑重构策略
在物理空间映射上的有效性，可为后续机电系统的高频姿态跟随提供高精度的视
觉前馈信息。

3.7 本章小结
   本章主要针对无人机探测任务中远距离微小目标的特征剥落，以及高速机动
带来的动态模糊等困难，对 Yolov11 目标检测算法进行了架构重构。首先，本章探
讨了基于上下文锚点注意力 CAA 与 Focaler-IoU 损失函数的初步特征增强方案，
验证了其在复杂低空背景抑制中的有效性与局限性。在此基础上，为突破极小目
标 检 测 的 物 理 限 制 ， 本 文 基 于 MEDA-YOLO[19] 的 算 法 思 想 构 建 了
YOLOv11n-MEDA 高性能架构。通过重构 P2-P5 四头检测拓扑与引入 ADown、
DySample 等算子，实现了高分辨率空间特征的保真传递与内容感知重采样；通过
针对性地引入并适配 MSEF 多尺度边缘融合模块，有效剥离了动态模糊状态下的
高频边缘残差；通过剔除深层冗余注意力机制 C2PSA 模块，阻断了网络对大目标
深层语义特征的过度耦合风险；最后，采用 Focaler-IoU 损失函数重塑了边界框的
回归逻辑，大幅提升了模型在应对远距离劣质样本时的抗噪能与定位稳定性。本
章所完成的视觉算法架构重构，为下一章视觉-云台闭环追踪系统的工程化实现奠
定了坚实的高精度感知基础。
