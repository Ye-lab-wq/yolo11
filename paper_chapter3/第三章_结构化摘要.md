# 第三章：基于 YOLOv11 的微小无人机检测架构设计与实现

> 来源：学位论文原 PDF 第 22–41 页（论文印刷页码 14–33）。本文档是用于低 token 分析和复现的结构化索引，数学细节和图示以独立 PDF 为准。

## 1. 问题与基线缺陷

- 输入分辨率为 640×640 时，远距离无人机可小于 8×8 像素。YOLOv11 默认最小检测层 P3 为 8 倍下采样，极小目标在该层可小于 1×1 个响应单元。
- 高速运动和相机曝光导致动态模糊，抑制高频边缘，引起漏检、定位偏差和检测框抖动。

## 2. 方法路线

### 2.1 CAA 过渡方案

- 7×7 平均池化得到局部锚点。
- 1×11 和 11×1 深度条带卷积近似大感受野。
- 1×1 卷积和 Sigmoid 生成空间注意力。
- 论文实验表明 CAA 单独使用未提升精度，mAP50:95 从 54.48% 降至 53.94%。

### 2.2 YOLOv11n-MEDA 主方案

- 将 P3–P5 三检测头改为 P2–P5 四检测头，P2 在 640 输入下为 160×160。
- `ADown`：平均池化后按通道分成两支，分别使用 3×3 跨步卷积和 1×1 卷积，再拼接。
- `DySample`：原理上应预测采样偏移并用 `grid_sample` 进行内容感知上采样。
- `RepNCSPELAN4`：用 CSP/ELAN 式聚合扩大非线性表征。
- `MSEF`：用 3×3、5×5（项目实现还包含 7×7）平均池化提取低频分量，将局部特征与平滑特征作差，得到高频边缘残差并融合。
- `EMA`：只在 P2 分支引入 Efficient Multi-Scale Attention，用于抑制浅层背景高频噪声。
- 移除默认深层 `C2PSA`，论文理由是避免过度耦合大目标语义。

## 3. 边界框损失

论文对 Focaler-IoU 的定义是区间线性映射：

```text
IoU_focaler = clamp((IoU - d) / (u - d), 0, 1)
```

但上传项目的实际代码使用 `focal_weight=(1-IoU)^1.5` 并叠加到 IoU loss，与论文和 Focaler-IoU 官方实现不一致。

## 6. 复现时必须保留的差异项

1. ZIP 中缺少 `valid/images` 和 `valid/labels`，服务器原工作目录中仍有完整的 842 张验证集。
2. ZIP 中缺少 `ultralytics/nn/modules` 下的自定义模块；已从服务器原工作目录恢复。
3. 实际 `DySample` 文件只是双线性 `interpolate`，没有官方 DySample 的偏移预测和点采样，因此论文机理描述与训练代码不等价。
4. `meda_200/best.pt` 内记录的最佳验证指标为 P=0.93079、R=0.92096、mAP50=0.95884、mAP50:95=0.59071，与论文表格不完全一致。
