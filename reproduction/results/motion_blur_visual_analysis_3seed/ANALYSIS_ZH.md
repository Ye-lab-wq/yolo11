# 三随机种子运动模糊可视化分析

## 结论

图中的 `std` 是 **standard training（标准训练）** 的缩写，不是标准差。`P2 std` 的 P2 架构与 `P2 blur train` 相同，区别仅是后者在训练中加入在线运动模糊增强；两者测试时使用完全相同的输入。旧的三种子定性图比较标准训练的 `P2` 与动态模糊训练的 `P2+MSEF`，同时改变了结构和训练策略，因此不能单独归因于模糊训练。

[四档实际测试案例对照图](blur_training_only_seed1.png)固定 P2 架构和 seed 1：四行依次为清晰、轻度、中度、强度测试输入；每行左侧是带 GT 的实际模型输入（后三档由原图合成模糊），中间是标准训练 P2，右侧是开启运动模糊训练的 P2。清晰与轻度各示一张退化例（`TP50 1/1 → 0/1`），中度与强度各示一张改善例（`0/1 → 1/1`）。绿框为 GT、橙红框为预测；所有预测面板均叠加 GT，文字放在图外。案例按固定规则选自单目标、GT 框等效边长 16–150 原生像素的样本，再按 TP50、TP75、IoU 差值排序。清晰与轻度案例来自 `video1375` 的相近画面，不能当作两个独立来源。它们只用于说明可能出现的检测变化，不代表整体发生率。

同一 P2 架构、同一 seed 1 在 625 张原始来源测试图及其合成模糊副本上的 [AP50–95 测试结果图](p2_blur_training_test_seed1.png)：清晰 `55.21 → 53.31`（−1.91 百分点），轻度模糊 `54.68 → 53.41`（−1.27），中度模糊 `50.74 → 52.51`（+1.77），强模糊 `44.95 → 49.56`（+4.62）。差值使用原始未四舍五入的 CSV 数值计算，因此可能与表格中两个已取两位小数的显示值相减相差 0.01。该图比旧图更直接地展示模糊训练的收益与清晰图代价。

定性图下方的 `TP50/TP75` 是在固定 `conf=0.25` 下，以 IoU ≥0.50 / ≥0.75 为标准匹配到的真实目标数，例如 `TP50 1/1 · TP75 0/1` 表示一个 GT 被检测到，但框的位置不足以达到 0.75 IoU。它们是单张图片的计数，不是整套测试集的 AP50、AP75，也不包含对所有置信度阈值的积分。

旧图所比较的 `P2 std` 与 `P2+MSEF+blur train` 的三随机种子测试均值如下，只能作为组合方案的对比：

| 条件 | P2 AP50–95/% | P2+MSEF+动态模糊 AP50–95/% | 直接差值/百分点 |
|---|---:|---:|---:|
| 清晰 | 54.87 | 53.95 | -0.91 |
| 中度模糊 | 49.72 | 53.08 | +3.36 |
| 强模糊 | 43.71 | 49.49 | +5.78 |

模块效应分解显示，主要收益来自动态模糊训练：它在 P2 上对中度、强模糊分别提升 `+2.39`、`+4.94` 个 AP50–95 百分点。动态模糊训练后再加入 MSEF，分别再提升 `+0.97`、`+0.84` 个百分点。MSEF 是辅助增益，不是主要增益来源。

代价是清晰图上的轻微下降。动态模糊训练在 P2 上使清晰 AP50–95 降低 `1.06` 个百分点；动态模糊训练后加入 MSEF 可补回约 `0.14` 个百分点，最终净下降 `0.91` 个百分点。

## 模糊场景的可视化含义

[模糊场景三种子一致性图](qualitative_blur_consensus_3seed.png)中的四行均由固定规则自动筛选，要求最终模型相对标准 P2 的改善至少在两个随机种子上方向一致；实际四例都是 `3/3` 一致。

- 强模糊第 1 例：标准 P2 在三个种子中分别只检出 `1/2、0/2、0/2` 个 TP50；最终模型均恢复为 `2/2`，并全部达到 TP75。
- 强模糊第 2 例：标准 P2 三个种子均为 `0/2`；最终模型均为 `2/2`。这不是仅仅提高置信度，而是恢复了原本漏掉的两个目标。
- 中度模糊第 1 例：标准 P2 三个种子均只有 `1/2` 个 TP50；最终模型均为 `2/2`，定位质量也明显改善。
- 中度模糊第 2 例：标准 P2 三个种子均漏检；最终模型三个种子均达到 TP50 和 TP75。

全体 625 张图上的三种子一致性统计也支持这一机制：中度模糊下 TP50 改善/退化为 `36/3` 张，强模糊下为 `93/5` 张；TP75 改善/退化分别为 `43/19` 和 `84/15` 张。

## 清晰图性能下降的原因

[清晰图反例图](qualitative_clear_regressions_3seed.png)专门展示标准 P2 更好的反例。前三行是定位退化，第四行是真正的漏检退化：

- 第 1 行：标准 P2 的 IoU 在三个种子上为 `0.779/0.826/0.833`，最终模型为 `0.668/0.638/0.579`。目标仍被检出，但三个最终模型的框都跌破 IoU 0.75。
- 第 2 行：标准 P2 为 `0.752/0.756/0.759`，最终模型为 `0.679/0.712/0.695`。这是接近 AP75 判定边界时的稳定跨阈值退化。
- 第 3 行：标准 P2 为 `0.775/0.781/0.806`，最终模型为 `0.748/0.739/0.713`，同样表现为框位置偏移而非消失。
- 第 4 行：图中有两个目标。相对标准 P2，最终模型在三个种子上都少获得一个 TP50，属于真实漏检；聚焦裁剪显示的是退化最严重的目标。

全体清晰图中，三种子一致的 TP50 改善/退化只有 `4/3` 张，而 TP75 改善/退化为 `29/29` 张；mean-best-IoU 的改善/退化为 `279/331` 张。因此，清晰 AP50–95 的净下降主要表现为大量小幅定位变化略偏向不利方向，以及少数明显反例，而不是普遍性的大规模漏检。固定置信度下的 TP 数量不反映完整 PR 排序，因此不能仅凭 `4/3` 推断 AP50 必然上升。

## 使用限制

这里的「公开测试」仅是重建数据集中原始来源的 625 张测试图的代码命名，不是另一个数据集。模糊图由这 625 张图通过确定性运动模糊核生成，是压力测试副本，并非独立采集的真实动态模糊数据。训练时另有在线模糊增强（30% 概率，640 输入尺度下 3/5/7 像素核）；测试时对每张原始来源测试图固定生成轻/中/强三档（3/7/11 像素核），标签框保持不变。它能证明模型对这一合成扰动更稳健，但不能单独证明真实场景泛化。所有案例均为程序规则筛选；所有模型使用相同图像、原生像素裁剪、`conf=0.25`、`NMS IoU=0.70`，没有进行亮度、锐化、去噪或选择性图像增强。

[清晰/模糊输入局部放大对照](motion_blur_input_closeups.png)使用相同原生像素裁剪，仅为展示而放大；天空等低纹理背景及缩小后的拼图不容易显出模糊。绿色 GT 框现在叠加到每个模型预测面板，框线已减细。
